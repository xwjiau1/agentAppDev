# OpenManus通用任务助手

组织模型、浏览器、代码执行和MCP工具完成多步任务。

- 案例类型：完整应用
- 技术栈：OpenManus、Pydantic、FastAPI、MCP、浏览器工具
- 代码入口：[app.py](app.py)、[main.py](main.py)、[run_flow.py](run_flow.py)、[run_mcp.py](run_mcp.py)、[run_mcp_server.py](run_mcp_server.py)、[sandbox_main.py](sandbox_main.py)、[setup.py](setup.py)
- 验证状态：已检查文件复制、Python语法和文档链接，未安装历史依赖或调用外部服务。

## 实现流程

main.py创建Manus → ReAct循环 → think选择工具 → act执行工具 → 观察结果 → 达到停止条件；app.py提供任务界面。

## 使用条件

按项目requirements配置历史环境和config模型凭据。保留app、prompt、tool等本地模块；外部浏览器、搜索、MCP与沙箱服务需独立配置。未启动Agent或执行真实任务。运行生成的workspace、截图和调试日志未收录。

从本目录运行入口，涉及相对路径时保持现有内部目录。依赖文件随项目保留；未提供锁定依赖时，需根据导入配置环境，不能将语法检查视为运行验证。
