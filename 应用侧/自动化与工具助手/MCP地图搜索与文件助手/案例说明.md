# MCP地图搜索与文件助手

以MCP服务接入地图、联网搜索和本地文本文件工具。

- 案例类型：完整应用
- 技术栈：Qwen-Agent、FastMCP、Node.js MCP服务
- 代码入口：[assistant_mcp_amap_bot.py](assistant_mcp_amap_bot.py)、[assistant_mcp_tavily_bot.py](assistant_mcp_tavily_bot.py)、[assistant_mcp_txt_bot.py](assistant_mcp_txt_bot.py)、[txt_counter.py](txt_counter.py)
- 验证状态：已检查文件复制、Python语法和文档链接，未安装历史依赖或调用外部服务。

## 实现流程

Assistant配置mcpServers → stdio启动对应进程 → 工具发现与调用 → 模型整合工具结果。

## 使用条件

地图与搜索工具需各自API凭据及npx环境；本地txt服务需python与mcp包。从目录内运行以解析txt_counter.py。read_txt_file只检查后缀和存在性，没有限制路径穿越，需补充路径约束后用于真实文件服务。

从本目录运行入口，涉及相对路径时保持现有内部目录。依赖文件随项目保留；未提供锁定依赖时，需根据导入配置环境，不能将语法检查视为运行验证。
