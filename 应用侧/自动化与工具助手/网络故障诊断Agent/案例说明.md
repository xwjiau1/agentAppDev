# 网络故障诊断Agent

通过网络诊断工具组合解释用户报告的故障。

- 案例类型：完整应用
- 技术栈：LangChain create_agent、ChatTongyi
- 代码入口：[2-network_diagnosis_agent.py](2-network_diagnosis_agent.py)
- 验证状态：已检查文件复制、Python语法和文档链接，未安装历史依赖或调用外部服务。

## 实现流程

注册ping、DNS、接口检查、日志分析 → 模型选择工具 → 汇总消息输出。

## 使用条件

配置DASHSCOPE_API_KEY。执行前检查工具实际调用的是系统能力还是固定样例，返回值不能替代真实运维证据。

从本目录运行入口，涉及相对路径时保持现有内部目录。依赖文件随项目保留；未提供锁定依赖时，需根据导入配置环境，不能将语法检查视为运行验证。
