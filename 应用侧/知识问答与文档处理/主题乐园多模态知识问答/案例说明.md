# 主题乐园多模态知识问答

统一检索文档、海报和视频，并附加相关媒体。

- 案例类型：完整应用
- 技术栈：DashScope多模态Embedding、FAISS、python-docx、OpenAI兼容SDK
- 代码入口：[1-文本embedding.py](1-文本embedding.py)、[2-图片embedding.py](2-图片embedding.py)、[3-视频embedding.py](3-视频embedding.py)、[4-disney_build_index.py](4-disney_build_index.py)、[5-disney_query.py](5-disney_query.py)
- 验证状态：已检查文件复制、Python语法和文档链接，未安装历史依赖或调用外部服务。

## 实现流程

4-disney_build_index.py读取DOCX与媒体 → 统一向量空间入库 → 5-disney_query.py查询 → 文本构造回答 → 按意图附加媒体。

## 使用条件

配置DashScope凭据，先运行构建索引脚本再运行查询脚本。大型视频和索引不随仓库分发；媒体URL需要可访问，图文向量维度必须一致。

从本目录运行入口，涉及相对路径时保持现有内部目录。依赖文件随项目保留；未提供锁定依赖时，需根据导入配置环境，不能将语法检查视为运行验证。
