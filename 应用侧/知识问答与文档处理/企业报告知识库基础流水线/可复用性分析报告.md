## 四、最佳实践建议

### 4.1 推荐复用顺序

```
Phase 1: 快速验证
├── prompts.py（直接使用）
├── api_requests.py（直接使用）
└── ingestion.py → VectorDBIngestor

Phase 2: 精度优化
├── retrieval.py → VectorRetriever
├── reranking.py → LLMReranker
└── ingestion.py → BM25Ingestor

Phase 3: 端到端
├── pdf_parsing.py → PDFParser
├── text_splitter.py → TextSplitter
├── tables_serialization.py → TableSerializer
└── pipeline.py → Pipeline
```

### 4.2 性能调优建议

**向量检索优化**：
```python
# 使用混合检索提升精度
hybrid = HybridRetriever(...)
hybrid.retrieve_by_company_name(
    company_name="xxx",
    query="xxx",
    llm_reranking=True,           # 启用重排序
    llm_reranking_sample_size=30, # 扩大候选集
    top_n=6                        # 适当增加输出
)

# 调整融合权重
llm_weight=0.7  # 70% LLM + 30% 向量
```

**并发处理**：
```python
# PDF 解析并行
parser.parse_and_export_parallel(
    input_doc_paths=pdfs,
    optimal_workers=8,  # CPU 核数
    chunk_size=2
)

# 表格序列化并行
serializer.process_directory_parallel(
    input_dir="./parsed",
    max_workers=10
)
```

### 4.3 成本优化建议
