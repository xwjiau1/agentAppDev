# 企业报告问答与回归评估

处理企业报告，按公司检索并生成带引用的答案。

- 案例类型：完整应用
- 技术栈：Docling、FAISS、BM25、Pydantic、Click、DashScope
- 代码入口：[1-情感分析-Qwen.py](1-情感分析-Qwen.py)、[dashscope-embedding-1.py](dashscope-embedding-1.py)、[main.py](main.py)、[setup.py](setup.py)
- 验证状态：已检查文件复制、Python语法和文档链接，未安装历史依赖或调用外部服务。

## 实现流程

CLI以数据目录为cwd → PDF解析 → 表格可选序列化 → 合并和切分 → 索引 → QuestionsProcessor → 结构化回答。

## 使用条件

main.py以Path.cwd作为数据根目录，需进入实际数据集目录后使用相对路径调用CLI。准备报告PDF、公司清单、问题集与独立凭据。增强基础版另有scripts/build_my_set.py及eval_my_set.py；交互版通过streamlit运行app_streamlit.py。

从本目录运行入口，涉及相对路径时保持现有内部目录。依赖文件随项目保留；未提供锁定依赖时，需根据导入配置环境，不能将语法检查视为运行验证。
