## 五、结果解读与局限性

**做对了什么**

- 公司名称路由（`_extract_companies_from_subset`）把每道题限定在对应公司的向量库内检索，4 家公司 4 个独立 FAISS 索引，无跨库串扰。
- 比较题走"分别抽取 → CoT 比较"的两段式流程（`process_comparative_question`），并在推理中显式核对币种一致后才下结论。
- 防幻觉题通过"公司名不在 subset 中即拒答"的规则正确返回 N/A，没有编造数字。

**局限性（评估 100% 的含金量时需打折）**

1. 样本量小（13 题），统计意义有限，单次 100% 不能外推为生产准确率。
2. 数据集为规则化虚构年报（`scripts/build_my_set.py` 生成），版式规整、无扫描件/复杂表格，比真实 PDF 解析场景简单——真实链路上 Docling 解析质量才是最大变量。
3. 数字型题目文本中直接出现答案，未覆盖需要跨页计算（如同比、合计）的题。
4. qwen-turbo 存在采样随机性，多次运行可能出现个别波动；建议固定 temperature 或用更强模型复核边界题。

## 六、后续建议

- 把 `data/my_set` 固化为回归评测集：每次改 prompt/检索参数后运行 `run_my_set_parallel.py` + `eval_my_set.py`，对比 `eval_result.json`。
- 扩充评测集：加入需要跨页计算、否定事实陷阱、同名公司歧义等更难的题型。
