# PDF问答与页码溯源

提取PDF文本并检索相关片段生成回答。

- 案例类型：完整应用
- 技术栈：PyPDF2、LangChain、FAISS、DashScope
- 代码入口：[chatpdf-faiss.py](chatpdf-faiss.py)
- 验证状态：已检查文件复制、Python语法和文档链接，未安装历史依赖或调用外部服务。

## 实现流程

PDF提取文本和页码 → 重叠切分 → 向量化入库 → TopK检索 → stuff问答链 → 输出来源页码。

## 使用条件

需 DASHSCOPE_API_KEY 和随项目保留的PDF。旧版 langchain.chains 等导入可能需要匹配旧依赖；页码通过字符串匹配估算，不能保证所有切片精确对应。

从本目录运行入口，涉及相对路径时保持现有内部目录。依赖文件随项目保留；未提供锁定依赖时，需根据导入配置环境，不能将语法检查视为运行验证。
