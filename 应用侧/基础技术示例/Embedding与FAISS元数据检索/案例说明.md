# Embedding与FAISS元数据检索

生成文本向量并将搜索结果映射回业务元数据。

- 案例类型：基础技术示例
- 技术栈：OpenAI兼容SDK、NumPy、FAISS
- 代码入口：[1-embedding计算.py](1-embedding计算.py)、[2-embedding-faiss-元数据.py](2-embedding-faiss-元数据.py)
- 验证状态：已检查文件复制、Python语法和文档链接，未安装历史依赖或调用外部服务。

## 实现流程

文档 → embedding → IndexIDMap存储 → 查询embedding → 返回ID → 元数据映射。

## 使用条件

需要 DASHSCOPE_API_KEY、FAISS与模型API；维度配置需与索引一致。

从本目录运行入口，涉及相对路径时保持现有内部目录。依赖文件随项目保留；未提供锁定依赖时，需根据导入配置环境，不能将语法检查视为运行验证。
