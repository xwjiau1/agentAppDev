# BGE与GTE文本向量推理

比较本地Embedding模型的向量生成与相似度计算。

- 案例类型：模型与服务示例
- 技术栈：FlagEmbedding、SentenceTransformers、PyTorch、ModelScope
- 代码入口：[bge-m3使用.py](bge-m3使用.py)、[gte-qwen2-使用1.py](gte-qwen2-使用1.py)、[gte-qwen2-使用2.py](gte-qwen2-使用2.py)
- 验证状态：已检查文件复制、Python语法和文档链接，未安装历史依赖或调用外部服务。

## 实现流程

下载模型 → BGE批量编码或GTE指令编码 → 归一化池化或高层encode → 矩阵乘法计算相似度。
