# 二手车价格预测与模型融合

对结构化车辆数据进行价格回归与多模型融合。

- 案例类型：模型与服务示例
- 技术栈：pandas、scikit-learn、CatBoost、LightGBM、XGBoost
- 代码入口：[data_preprocessing.py](data_preprocessing.py)、[feature_engineering_and_catboost.py](feature_engineering_and_catboost.py)、[model_ensemble.py](model_ensemble.py)、[predict_catboost.py](predict_catboost.py)、[train_catboost.py](train_catboost.py)、[train_lightgbm.py](train_lightgbm.py)、[train_xgboost.py](train_xgboost.py)、[view_data.py](view_data.py)
- 验证状态：已检查文件复制、Python语法和文档链接，未安装历史依赖或调用外部服务。

## 实现流程

探索数据 → 日期与类别预处理 → 训练回归器 → 验证MAE等指标 → 生成预测 → 按SaleID对齐加权融合。

## 使用条件

需原始used_car_train_20200313.csv与used_car_testB_20200421.csv；大型CSV未收录，按原文件名准备。先运行data_preprocessing.py，再训练模型；高级特征脚本为另一条CatBoost流程。此项目为预测模型示例，没有Agent调度层。

从本目录运行入口，涉及相对路径时保持现有内部目录。依赖文件随项目保留；未提供锁定依赖时，需根据导入配置环境，不能将语法检查视为运行验证。
