# Python基础面试速查

每篇只聚焦一个知识点，按“速记结论 → 面试问答 → 真实代码 → 易错追问”复习。示例来自本仓库应用，保留框架调用上下文；重点解释Python语言机制，不要求运行模型服务。

## 推荐复习顺序

1. 时间紧先读标记“必背”的对象、容器、参数、生成器、异常、类与异步。
2. 每篇能用30～60秒回答：是什么、解决什么问题、案例哪几行体现、最容易错在哪里。
3. 再看“常考”和“进阶”，把机制与框架行为区分开。不要把原代码的缺陷当成最佳实践。
