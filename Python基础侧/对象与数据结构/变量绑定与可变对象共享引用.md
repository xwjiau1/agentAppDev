# 变量绑定与可变对象共享引用

> 复习优先级：必背。先记结论，再用案例解释“这行代码做了什么、有哪些边界”。

## 面试速记

赋值把名字绑定到对象，不自动复制对象。list、dict、set可变；str、int、tuple本身不可变。通过别名原地修改对象，其他引用也会看到变化。

## 面试问答

**问：`b = a` 会复制列表吗？** 不会，只增加一个对同一列表的引用。`b.append(...)`会影响a观察到的内容，`b = []`则只重新绑定b。

**问：函数能修改调用方列表吗？** 可以原地修改同一列表；把形参重新赋值不会重新绑定调用方名字。

## 易错点与追问

不可变不代表内部对象都不可变：tuple包含list时，list内容仍可变。不要把“传引用”理解成函数能修改调用方变量绑定。
