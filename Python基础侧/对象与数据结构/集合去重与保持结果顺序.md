# 集合去重与保持结果顺序

> 复习优先级：必背。先记结论，再用案例解释“这行代码做了什么、有哪些边界”。

## 面试速记

set存放不重复的可哈希元素，适合成员查询；需要保留首次出现顺序时，可以同时使用set判断和list存结果。

## 面试问答

**问：为什么不用`list(set(items))`？** 它无法表达保留首次出现顺序的要求；set不是按插入顺序提供语义保证的容器。

**问：list或dict能直接放入set吗？** 通常不能，因为它们可变且不可哈希；tuple也需所有元素可哈希。

以下为当前仓库原代码，统一去除外层缩进；它是源码节选，不是独立运行程序。

```python
seen_contents = set()
unique_docs = []

for q in queries:
    docs = vectorstore.similarity_search(q, k=k)
    for doc in docs:
        content = doc.page_content
        if content not in seen_contents:
            seen_contents.add(content)
            unique_docs.append(doc)

return unique_docs
```

seen_contents用于快速检测；unique_docs保留首次召回的文档顺序。字符串page_content可哈希，文档对象本身无需可哈希。

## 易错点与追问

成员查询的平均复杂度通常为O(1)，不要承诺所有输入下恒定时间。这里按完整文本去重，会将来源不同但内容相同的文档合并。
