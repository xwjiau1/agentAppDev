# 列表切片与负数索引

> 复习优先级：必背。先记结论，再用案例解释“这行代码做了什么、有哪些边界”。

## 面试速记

索引取单项，切片`seq[start:stop:step]`取区间，右边界不包含。列表切片创建新的外层列表，元素仍可能共享。负数索引从末尾计数。

## 面试问答

**问：切片越界会怎样？** 通常被截到合法边界；单项索引越界会抛IndexError。

**问：`a[:]`和`a[::-1]`是什么？** 前者浅复制列表，后者建立逆序切片；都不是对嵌套对象深拷贝。

以下为当前仓库原代码，统一去除外层缩进；它是源码节选，不是独立运行程序。

```python
new_text = response[-1]['content']

if new_text != full_response:

    delta = new_text[len(full_response):]

    history[-1][1] += delta

    full_response = new_text
```

response[-1]取最后一条消息；new_text[len(full_response):]取得新增后缀。这里依赖新文本延续旧前缀，不能在模型重写前文时无条件当作增量。

## 易错点与追问

步长不能为0。`history[-1]`要求列表非空；嵌套history[-1][1]还要求最后一个元素至少含两项。
