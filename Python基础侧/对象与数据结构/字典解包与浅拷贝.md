# 字典解包与浅拷贝

> 复习优先级：必背。先记结论，再用案例解释“这行代码做了什么、有哪些边界”。

## 面试速记

`{**d, "k": v}`创建新字典；后出现的同名键覆盖前面的值。复制的是外层键值关联，嵌套对象仍可能共享。

## 面试问答

**问：`**state`有什么作用？** 在字典字面量中展开键值对；在函数调用中则展开关键字实参。

**问：为什么这不是深拷贝？** 新字典内的列表、字典等值仍指向原来的对象；只修改嵌套对象会互相影响。

```python
updated_state = {
    **state,
    "query_type": query_type,
    "processing_mode": processing_mode,
}
return updated_state
```

先展开state，再覆盖query_type与processing_mode，返回新外层字典。与直接state["processing_mode"]=...的原地修改不同。

## 易错点与追问

本例只覆盖模式字段；不能据此外推所有状态节点都无副作用。`copy.deepcopy`递归复制受支持的对象，也有共享引用、循环引用和自定义复制行为需要考虑。
