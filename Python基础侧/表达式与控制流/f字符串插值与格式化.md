# f字符串插值与格式化

> 复习优先级：必背。先记结论，再用案例解释“这行代码做了什么、有哪些边界”。

## 面试速记

f字符串在运行时计算花括号内的表达式；`{value:.2f}`表示小数格式，`{{`与`}}`输出字面花括号。

## 面试问答

**问：f字符串会延迟到打印时才计算吗？** 不会，在执行该字符串表达式时就计算。

**问：能把f字符串拼SQL当作安全参数化吗？** 不能；格式化不做SQL转义或参数绑定。
