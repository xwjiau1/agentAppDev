# 列表推导式与过滤条件

> 复习优先级：必背。先记结论，再用案例解释“这行代码做了什么、有哪些边界”。

## 面试速记

`[表达式 for 变量 in 可迭代对象 if 条件]`创建列表；先遍历、过滤，再计算输出表达式。适合短而清楚的数据转换。

## 面试问答

**问：推导式和普通for的区别？** 推导式表达构造结果，for更适合复杂分支和副作用。Python 3推导式的循环变量通常不泄漏到外层。

**问：列表推导式是否惰性？** 不是，会立即构造结果；圆括号形式通常是生成器表达式。
