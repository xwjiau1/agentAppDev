# lambda匿名函数与排序键

> 复习优先级：必背。先记结论，再用案例解释“这行代码做了什么、有哪些边界”。

## 面试速记

lambda定义单表达式函数，参数规则与普通函数类似；常用作key或短回调。复杂逻辑应使用def。

## 面试问答

**问：`key=lambda x: x[1]`怎么排序？** 为每个元素计算第二项作为排序键，返回值决定排序次序。

**问：lambda会立刻执行吗？** 定义时创建函数对象，调用时才执行表达式。

## 易错点与追问

lambda同样遵循作用域规则，也可能遇到闭包晚绑定。不要用lambda隐藏复杂控制流。
