以下为当前仓库原代码，统一去除外层缩进；它是源码节选，不是独立运行程序。

```python
@tool
def calculator(expression: str) -> str:
    """计算数学表达式。只接受数字和运算符，例如: 2+2, 100/4, 32*1.8+32。不要使用变量名或占位符。"""
    # 只允许数字、运算符和括号
    import re
    if not re.match(r'^[\d\s\+\-\*\/\.\(\)]+$', expression):
        return f"错误: 表达式 '{expression}' 包含无效字符。请只使用数字和运算符(+,-,*,/)"
    return str(eval(expression))
```

tool在定义时将calculator转换或注册为框架工具；函数签名和文档字符串提供参数与用途说明。正则过滤后调用eval仍需评估资源消耗，不应当作通用安全求值器。

## 易错点与追问

注册工具和调用追踪都是框架赋予装饰器的行为；Python语法本身不会自动调用模型。
