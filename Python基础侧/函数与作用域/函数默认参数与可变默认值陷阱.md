# 函数默认参数与可变默认值陷阱

> 复习优先级：必背。先记结论，再用案例解释“这行代码做了什么、有哪些边界”。

## 面试速记

默认参数在执行def定义时求值，而非每次调用重新创建。可变默认对象可能跨调用共享，通常用None作缺省标记并在函数内创建。

## 面试问答

**问：为什么`def f(items=[])`会累积上次结果？** 每次省略实参时拿到同一个默认列表，原地修改会被保留。

**问：None默认值一定意味着允许None业务输入吗？** 不一定，需要自己区分“缺省”与“显式传None”的语义。

## 实际案例与代码

[Word2Vec词向量训练](../../应用侧/模型与服务示例/Word2Vec词向量训练/案例说明.md) · [segment.py，134–139行](../../应用侧/模型与服务示例/Word2Vec词向量训练/utils/segment.py#L134-L139)

以下为当前仓库原代码，统一去除外层缩进；它是源码节选，不是独立运行程序。

```python
def delete_stopwords(lines_list, stopwords= []):
    sentence_segment=[]
    for word in lines_list:
        if word not in stopwords:
            sentence_segment.append(word)
    return sentence_segment
```

函数接收stopwords=[]，每次调用新建sentence_segment但不新建默认stopwords。当前只做成员判断，若后续append默认列表就会产生跨调用影响。

## 易错点与追问

本例默认stopwords虽是列表，但片段没有修改它；应说明风险而不是声称已经发生污染。
