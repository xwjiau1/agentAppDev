# 字典分派表与可调用对象

> 面试复习：先讲机制，再用Harness代码解释状态、边界和失败处理。

## 面试速记

函数是对象，可以存入dict、赋值、作为参数传递。分派表用字符串查找函数，再把输入解包交给它，减少重复if分支。

## 面试问答

**问：存函数名和调用函数有什么区别？** `f`是函数对象，`f()`执行后取得返回值。

**问：能把不受信任的名字直接映射到任意Python函数吗？** 不应这样设计；分派表应明确列出允许的处理器。

### 运行时分派

[s02_tool_use/code.py，180–183行](../../应用侧/自动化与工具助手/通用AgentHarness/s02_tool_use/code.py#L180-L183)

```python
handler = TOOL_HANDLERS.get(block.name)
output = handler(**block.input) if handler else f"Unknown: {block.name}"
print(str(output)[:200])
results.append({"type": "tool_result", "tool_use_id": block.id, "content": output})
```

按模型工具名查找函数，并用**展开参数；未知工具返回错误文本，参数不匹配仍可能抛TypeError。

## 易错点与追问

字典分派只是查找机制，不会自动验证权限、参数schema或异常；边界必须另行实现。
