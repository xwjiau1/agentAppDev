# with上下文管理与文件关闭

> 复习优先级：必背。先记结论，再用案例解释“这行代码做了什么、有哪些边界”。

## 面试速记

with通过上下文管理协议进入和退出资源范围；退出时调用__exit__，即使代码块抛异常也会尝试清理。文件对象可据此自动关闭。

## 面试问答

**问：with会自动吞异常吗？** 不一定；__exit__返回真值可以抑制异常，通常文件上下文不这么做。

**问：with与try/finally的关系？** with封装可复用的资源获取与释放协议，不只用于文件。

## 实际案例与代码

[GUI视觉动作生成](../../应用侧/多模态与行业应用/GUI视觉动作生成/案例说明.md) · [2-gui-plus使用.py，13–15行](../../应用侧/多模态与行业应用/GUI视觉动作生成/2-gui-plus使用.py#L13-L15)

以下为当前仓库原代码，统一去除外层缩进；它是源码节选，不是独立运行程序。

```python
with open(image_path, "rb") as image_file:

    return base64.b64encode(image_file.read()).decode('utf-8')
```

以rb模式读取图片为bytes；base64.b64encode返回bytes，再decode得到可写入JSON的字符串。离开with后文件句柄关闭。

## 易错点与追问

文件可能不存在或解码失败，with不代替异常处理。不要将二进制read结果直接当str使用。
