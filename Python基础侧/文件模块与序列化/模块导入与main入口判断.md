# 模块导入与main入口判断

> 复习优先级：必背。先记结论，再用案例解释“这行代码做了什么、有哪些边界”。

## 面试速记

模块首次导入通常执行顶层语句，并缓存到sys.modules。`if __name__ == "__main__":`让入口代码只在作为主模块运行时执行。

## 面试问答

**问：import模块会执行函数体吗？** 仅定义函数通常不执行函数体，但顶层函数调用、装饰器表达式等会执行。

**问：main判断能消除所有导入副作用吗？** 不能，判断外的顶层代码照常执行。

以下为当前仓库原代码，统一去除外层缩进；它是源码节选，不是独立运行程序。

```python
if __name__ == "__main__":
    # 示例1：文本分析（单个工具调用）
    result1 = lcel_task_chain("文本分析", {"text": "这个产品非常好用，我很喜欢它的设计，使用体验非常棒！"})
    print("示例1结果（文本分析）：", result1)
    print("-" * 30)
```

直接运行脚本时执行示例调用；作为模块导入时跳过该分支，但此前的类定义和工具对象构建仍可能发生。

## 易错点与追问

同一文件以不同模块名加载可能导致重复状态。可导入模块不应在顶层无条件启动GUI或请求外部服务。
