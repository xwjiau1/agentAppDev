# 正则表达式与原始字符串

> 复习优先级：常考。先记结论，再用案例解释“这行代码做了什么、有哪些边界”。

## 面试速记

re用于模式匹配与替换，r字符串避免Python先解释反斜杠；它不会改变正则引擎自身对反斜杠的含义。match从开头匹配，search查找任意位置。

## 面试问答

**问：验证整个输入用match就够了吗？** 一般应明确锚点或使用fullmatch；是否允许尾换行等边界也要确认。

**问：原始字符串能以单个反斜杠结尾吗？** 不能，字符串词法仍有约束。

以下为当前仓库原代码，统一去除外层缩进；它是源码节选，不是独立运行程序。

```python
if not re.match(r'^[\d\s\+\-\*\/\.\(\)]+$', expression):
    return f"错误: 表达式 '{expression}' 包含无效字符。请只使用数字和运算符(+,-,*,/)"
return str(eval(expression))
```

字符集合允许数字、空白和少数算术符号，再交给eval。字符合法不等于计算资源安全，例如大幂运算仍可能非常昂贵。

## 易错点与追问

正则只验证文本模式，不能完整表达复杂业务权限；大输入与复杂回溯模式还可能导致性能问题。
