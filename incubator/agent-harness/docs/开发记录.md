## 2026-11-24：CI 检出失败排查

远端运行 45244255998 的 Ubuntu 日志显示，actions/checkout 全仓检出时遇到历史资料中的超长 docx 文件名（File name too long），Python 安装、静态检查和测试均未执行。Windows 作业被默认矩阵 fail-fast 取消，不能解释为 Windows 测试失败。

修复 CI：通过 sparse-checkout 仅检出 incubator/agent-harness，保留原资料；设置 fail-fast=false，让两种系统独立完成；setup-python 使用项目 .python-version，避免与 uv 选取版本不一致。本次不修改 Agent 代码。修复后的远端执行结果以该提交的 Actions 页面及当次交付消息为准。

后续运行 45244873933 确认 sparse-checkout 已通过，暴露环境版本问题：ubuntu-latest 已指向 26.04，而 Python 3.12.8 不提供该系统构建。核对 actions/python-versions 官方清单后，将 Linux runner 固定为受支持的 ubuntu-24.04；保留项目 Python 版本，不因 CI 镜像滚动升级改变运行基线。

最终运行 45244992636 在提交 47b9437 上确认 Windows/Linux 两个作业全部成功。
