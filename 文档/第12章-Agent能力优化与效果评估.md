# 第12章：Agent能力优化与效果评估

> 首版审阅稿 · 2026-11-09。整理依据为本地课件、课堂笔记和案例源码，不代表框架当前版本的通用使用指南。

## 本章要解决什么

本章的核心是让 Agent 的“处理过程可观察、回答效果可比较”。投顾助手作为被测应用：简单问题走反应式路径，复杂问题经过数据收集、分析和建议；随后用规则与模型评分检查行为，并用追踪记录定位问题。能力优化体现为这些证据支持的后续迭代，本章没有实现自动搜索最优提示词或模型训练闭环。
