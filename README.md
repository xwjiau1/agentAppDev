## 使用说明

- 优先阅读案例说明，再按入口配置依赖、凭据和数据；代码片段是源码摘录，不是独立运行程序。
- 历史SDK和框架接口未统一迁移，静态检查通过不代表外部服务调用已经验证。
- 模型权重、大型原始数据和运行缓存不入库，相关条件在案例中说明；不携带现有账号的访问凭据。
- 第三方项目的许可证和作者信息随源码保留。本仓库不为第三方代码重新授予许可证。
